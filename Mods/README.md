# Выбор модов

Открой `Mods.ini` и поставь `1`, чтобы включить мод, или `0`, чтобы выключить.

Например, запуск без оптимизатора производительности:

```ini
[Mods]
ExpandedSettings=1
PerformanceOptimizer=0
VideoCrashFix=1
```

Изменения применяются при следующем запуске игры. Моды, которых нет в списке, по умолчанию включены.

`StormBench` — инструмент для замеров FPS, его включает только `tools\bench.ps1` на время прогона. Оставь `0`.
