# Выбор модов

Чтобы включить мод, укажите для него `1` в файле `Mods.ini`, чтобы выключить — `0`.

Пример запуска без оптимизатора производительности:

```ini
[Mods]
ExpandedSettings=1
PerformanceOptimizer=0
VideoCrashFix=1
AutoUpdate=1
```

Изменения вступают в силу при следующем запуске игры. Моды, отсутствующие в списке, включены по умолчанию.

`AutoUpdate` проверяет наличие новой версии при запуске игры. `StormBench` — инструмент разработчика для замеров
FPS, его включает только `tools\bench.ps1` на время замера.
