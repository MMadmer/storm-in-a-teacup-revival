# Auto Update

Checks GitHub for a newer release when the game starts and offers to install it before the game window switches
to fullscreen. Only the files that changed are downloaded; the game restarts on the new version. Settings files
are kept. Set `AutoUpdate=0` in `Mods.ini` to turn the check off.

The release and update contract is described in [docs/AUTO_UPDATE.md](../../docs/AUTO_UPDATE.md).
